# Personal OS / NEO v2 Hybrid

This package keeps the working NEO/Supabase engine and overlays the clean/gaming Life RPG visual language.

## Kept from NEO
- Supabase
- auth
- tasks
- true planner
- drag/move/resize timeblocks
- capacity
- projects
- finance
- daily logs
- proof
- XP completion logic

## Added from Life RPG
- compact KPI strip
- cream/wine/gold visual system
- more dopamine-oriented metrics
- dark BFI/wealth card
- cleaner card hierarchy
- level-up modal shell
- reduced oversized cinematic feel

## Deploy
Replace the current `/neo` repo contents with this package.
Do not change Supabase credentials.
No new SQL is required for the UI merge.
